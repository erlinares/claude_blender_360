# Créditos

- **Poly Haven** (https://polyhaven.com): modelos, texturas y cielos HDRI con licencia **CC0** (dominio público). No vienen en el repo; `tools/blender/fetch_assets.py` los descarga de su API pública.
  - Modelos: tree_small_02, jacaranda_tree, island_tree_01/02/03, fern_02, grass_medium_01/02, street_lamp_01, wooden_picnic_table, painted_wooden_bench, shrub_02, shrub_04, flower_gazania, flower_heliophila, coast_rocks_01.
  - Texturas: thatch_roof_angled, coral_stone_wall, wood_floor_deck, weathered_planks, palm_tree_bark, coast_sand_01, cobblestone_floor_04, asphalt_02, leafy_grass, forest_leaves_02, concrete_floor_02, bark_brown_02, brushed_concrete.
  - HDRI: belfast_sunset_puresky, kloofendal_48d_partly_cloudy_puresky.
- **Blender** (https://www.blender.org), GPL. Se usa como herramienta y no se distribuye aquí.
- **three.js** r128 (https://threejs.org), MIT. Se carga desde cdnjs.
- La duela de la cancha y la fronda de palma se generan con `tools/blender/make_textures.py`, que es parte de este repo (MIT).
